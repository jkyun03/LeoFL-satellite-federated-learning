# 🛰️ 저궤도 위성 기반 연합학습(LEO Federated Learning) 시뮬레이션 시나리오

이 문서는 저궤도 위성(LEO) 환경에서의 연합학습(FL) 시뮬레이션을 3가지 조건으로 구분하여 정리한 것입니다.  
각 시나리오는 위성의 연결 상태, 학습 시간(local training time), 전역 모델 업데이트 시점을 다르게 설정합니다.

---

## 🕒 이벤트 타임라인 (예시)

| 시간(초) | 이벤트 설명 | 연결 상태 | 비고 |
|-----------|--------------|------------|------|
| 0         | 지상국(Global Station)에서 전역 모델 초기화 | GS | 전역 모델 v0 배포 |
| 120       | 위성 1 연결 → 전역 모델 수신 | GS ↔ Sat-1 | 로컬 학습 시작 |
| 240       | 위성 2 연결 → 전역 모델 수신 | GS ↔ Sat-2 | 로컬 학습 시작 |
| 360       | 위성 1 로컬 학습 완료 | Sat-1 | 가중치 업로드 |
| 420       | 위성 2 로컬 학습 완료 | Sat-2 | 가중치 업로드 |
| 480       | 지상국이 모든 위성의 가중치 수신 후 전역 모델 v1 갱신 | GS | 다음 주기 배포 예정 |

---

## ⚙️ 시뮬레이션 조건

### 1️⃣ **항상 연결됨 + 학습 시간 동일**
- 모든 위성이 지상국과 항상 연결 유지  
- 각 위성의 학습 시간이 동일  
- 일정 주기로 전역 모델이 업데이트됨  
- ✅ **목표:** 기본 성능(Baseline) 확인

---

### 2️⃣ **간헐적 연결 + 학습 시간 동일**
- 모든 위성이 지상국과 간헐적 연결 
- 위성별 학습 시간이 동일   
- 모든 위성이 학습 완료 시 전역 업데이트 수행 - 동기식 연합학습
- ✅ **목표:** 간헐적 연결 환경에서 연합학습 성능 확인

---

### 3️⃣ **간헐적 연결 + 학습 시간 다름**
- 위성이 주기적으로만 지상국과 연결 (예: 300초 주기)  
- 연결되지 않은 동안에는 로컬 학습만 진행  
- 모든 위성의 가중치가 도착해야 전역 모델 업데이트 수행  
- ✅ **목표:** 간헐적 연결 환경에서의 비동기 FL 성능 평가
